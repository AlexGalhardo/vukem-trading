the real market. Paper-only accounts have feed limitations; validate the chosen plan.

guarantee exactly-once execution. Do not assume B3 support.

## Market-data providers

One row per provider in `internal/providers` and per import path. Record a provider's terms here before
relying on it; public endpoints used by hobby tools are often limited to personal or research use.

| Provider | Markets | Credentials | Terms and notes |
| --- | --- | --- | --- |
| Alpaca IEX (`alpaca`) | US equities and ETFs | `ALPACA_API_KEY`, `ALPACA_API_SECRET` (paper) | Free IEX feed, delayed about 16 minutes and not the consolidated market. Alpaca's data and paper-trading terms apply. See [Alpaca paper trading](https://docs.alpaca.markets/us/docs/paper-trading). |
| Binance (`binance`) | Crypto spot (BTCUSDT, ETHUSDT) | none | Public klines endpoint; closed 5-minute candles only. Binance market-data terms apply: personal, non-commercial use. Rate limits apply; the adapter pages 1000 candles per request and limits a request to 30 days. |
| B3 CSV import | B3 equities | none | Licensed intraday data supplied by the owner. The importer stores source, license and SHA-256 and rejects anything outside the reviewed 2026 calendar. No public intraday source is assumed. |
| FX CSV import | Spot forex | none | Owner-supplied data with a stated source and license. There is no central tape for spot FX, so spreads and prices differ by venue; results are indicative. |
| Crypto CSV import | Crypto spot | none | Owner-supplied or exported data, 24/7 UTC sessions. |
| Alpaca IEX daily bars (`reco.AlpacaDaily`) | US equities, daily ranking | `ALPACA_API_KEY`, `ALPACA_API_SECRET` (free paper key) | Historical daily bars, `feed=iex`, split-adjusted, one paged multi-symbol request. IEX prices and volume only, not the consolidated tape. Alpaca data terms apply. See [Market data API](https://docs.alpaca.markets/reference/stockbars). |
| Binance daily klines (`reco.BinanceDaily`) | Crypto spot, daily ranking | none | Public `data-api.binance.vision` market-data host, closed UTC days only, 1000 bars per request. Binance market-data terms: personal, non-commercial use. |
| B3 end of day | B3 | none | **Not supported.** brapi's free plan needs a token, serves one ticker per call and its terms were not verified; Stooq answers server requests with a JavaScript challenge. |
